## Why this video

A timelapse is a pose-making session with the thinking sped up: the value is the sequence of decisions — what gets posed first, what gets revisited, how a pose is read and corrected at speed. Fifteen minutes of another artist's hands is a cheap audit of our own posing order.

## SHOULD-BE-SEEN (written before viewing)

A working session producing a set of character poses (witch-themed set), start to finish, at timelapse speed — pose order and revision pattern visible, commentary absent.

## Timed observation focus

- Pose order: which body part/chain is set first for each pose, across the set — the pattern is the extraction.
- Revisits: poses returned to, and what changed on the return.
- Reading distance: how often the artist zooms out / checks the silhouette.

## Distillation targets

1. **Posing order grammar** — the repeatable sequence under the speed. Question: does it match our sprite-acting order (weight, spine, head, hands) or improve it?
2. **Revision triggers** — what sends the artist back. Question: nameable checks, or taste?

## Clean-room rebuild spec

Run the distilled order on one estate pose set (a companion expression set); time and revision counts compared against our current order on the same set.
