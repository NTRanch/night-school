### T-01 — Shot construction: two-pose shot, then shift all rig keys +50 so frame 0 is the T-pose
**Verdict: Adapt** · Claims: C-03

- **(a) Settings / steps (observation §§02:30–10:00, timed
  record):** The shot is pose **15** at the start → a second
  pose **48 frames** later, built in a Pose Library of **18
  poses** ("just a motion… a test"; the file opens with pose
  16 already applied — a different moment, Finding 4). Then
  **all rig keyframes are shifted +50 frames** [SPEECH:
  "shift all keyframes on rig by 50"], putting a T-pose at
  the head of the range; the util objects' actions are keyed
  at frame **50** [SCREEN, g05/g07]. The shift exists for one
  reason: the collision remesh is built from frame 0, so
  frame 0 must be the T-pose (T-10).
- **(b) Mechanism:** Proxy construction needs a canonical
  rest configuration; performance needs its own start. Rather
  than building the proxy on a posed frame, the timeline is
  re-based so the rest pose occupies the construction frame
  (0) and the performance begins at a known offset (50) —
  construction frame and performance start become two named,
  separable facts, and every downstream start value (sim
  start frame, T-15) keys off the offset.
- **(c) Estate (D-1):** The principle transfers: collider
  construction happens on the rest configuration, never on a
  performance frame. ESTATE: the fleet's rest pose is the
  rigs' own rest configuration and the D-1 loop is a
  period-78 clip at 60 Hz with Contact at sample 38 — there
  is no +50 numeral to copy. The estate form is: build the
  collider from the evaluated rest mesh, author the fluid
  timing relative to the clip's named beats.
- **(d) Adapt — what changes and why:** The source's offset
  is a hand shift of every key in an interactive session;
  the estate build is scripted, so the offset is a build
  parameter recorded in the run record, applied to the
  authored data — and per Finding 6, timing is stored
  beat-relative, not as shifted absolutes.
- **Invariants / failure modes:** Invariant — the frame the
  proxy is built from is the rest/T-pose, by construction,
  not by scrubbing to a pose that looks neutral. Failure
  mode: shifting some channels and not others (the util
  objects carry their own actions; in the source they are
  keyed at 50 too) — a partial shift desyncs emitter and
  body by exactly the offset.
