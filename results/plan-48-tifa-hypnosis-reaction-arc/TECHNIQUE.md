## Arc (in scope)

Baseline (0–3 s) → Onset (3–6 s: gaze locks; iris emissive shift +
pupil contraction — the face changes ~2 s before the body stops
defending) → Deepening (6–18 s: eyelids to half, guard hands lower)
→ Surrender (18–33 s: eyes close fully, head bows; hands change
sides, defence → self-touch) → Standing peak (33–47 s: eyes roll up,
tongue emerges) → Trance peak (48–51.5 s: postural failure, reclined,
unfocused glowing eyes, sustained open-mouth gasp).

## Grammar yield (portable mechanisms, scene-spec terms)

1. **Two-step eye-state signifier.** `iris_emissive` runs a hue
   ramp — natural → amber → magenta — with pupil contraction at the
   first step. Onset ramp ≈1 s, then persistent. Against Plan 54's
   binary iris flip, the intermediate hue buys a readable *falling*
   phase. **Transfers as-is.**
2. **Gaze-lock precedes state change.** `gaze_target` pins to the
   stimulus point ~2–3 s before any iris change; induction is
   performed by attention, then marked by the eyes. **Transfers
   as-is.**
3. **Four-state eyelid ladder.** open → half (fixation) → closed
   (surrender) → rolled (peak). One lid key per stage; the
   closed-eye beat is the surrender marker and must not be merged
   with the rolled-eye peak. **Transfers as-is.**
4. **Brow/mouth pairing, tongue as peak-only key.** Brows raise at
   onset and hold; mouth runs closed → parted → soft smile (at the
   closed-eye beat) → wide + tongue. `tongue_out` fires only in the
   peak stage. **Transfers as-is.**
5. **Hand-agency transfer.** The same hands run guard (palms out,
   shoulder height) → lowered → self-touch; the transfer moment is
   the surrender tell, readable in wide shot. **Register
   translation:** in the source the transfer reads as compulsion
   overriding defence. Under Prima's willing register the guard
   beat is re-authored as hesitation/play — hands rise in tease and
   lower by choice — and self-touch as invitation. Poses and timing
   transfer; the coercion semantics do not.
6. **Postural-tone drain ladder.** braced upright → wall-supported
   → swaying → folded → reclined: five support states, each needing
   more from the environment than the last. **Transfers as a timing
   scaffold; register translation:** in the willing register the
   recline is chosen languor — same poses, muscle-tone read soft
   rather than slack.
7. **Light-as-cause staging.** The stimulus carries its own point
   light; the warm wash on the face intensifies with trance depth,
   so lighting level doubles as a stage meter — the audience can
   read the state value off the key light. **Transfers as-is.**
8. **Peak needs an exit the source doesn't have.** The final in-scope
   keys (unfocused up-gaze, sustained gasp) are, in the source, the
   prelude to the excluded turn. In a willing-register scene the
   same keys read as peak abandon and **require** a
   release/aftercare beat the source never provides. Flagged as
   translation-with-addition — do not import the arc's ending
   shape, only its stages.
