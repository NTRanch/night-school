## Candidate 1 — A plan's premise is a claim; gate it like one

**Lesson:** A curriculum plan written from a title + category
listing can be wholly wrong about its video. Plan 35's video
("How NOT to Make Rule 34 Renders in Blender", rule34video
3352570) was planned as a named-defect failure catalogue; the
actual video is a behind-the-scenes Blender posing recording
set to music — zero named defects, zero stated causes, no
narration at all. The page's own description said so all along
("behind the scenes of a romantic fan fiction comic"); the
plan's intake never read it against the premise.

**Mechanism / evidence:** the run's structure caught it —
SHOULD-BE-SEEN written before viewing, screen-governs
discipline, and a claims list with the plan's premise itself
as claim C-35-1, marked REFUTED with frame evidence
(OBSERVATION.md §1, §6 in the run dir).

**Transferable rule:** every study plan's premise is a Pass 1
claim, tested first; when it fails, the run reports the
refutation as the finding and re-sources any downstream
deliverable honestly (here: candidate gate checks re-sourced
to the plan's pre-viewing categories + the estate's own
evidenced defect record, never to the video). A taxonomy
"extracted" from a video that contains none would have been
fabricated provenance entering the gate system itself.

## Candidate 2 — Spec-relative and benchmark-scoped, or the check false-fires on keepers

**Lesson:** Two candidate gate checks derived from defect
classes false-fired on known-good keepers until scoped:
(a) a framing-crop check fires on deliberate partial-crop
keepers (3 of 10 D-802 stylesheet stills) unless it applies
only where full-body-in-frame is specified; (b) a glyph/print
check fires on specified body text/tattoos (Katya's "FREE USE"
marking, Cordelia's D-799 womb tattoo) unless it is
spec-relative — print is a defect only against the artifact's
own spec. Evidence: `PASS3-CANDIDATE-CHECKS.md` §3–§4 in the
run dir (20 artifacts exercised: 10 keepers / 3 rulable /
7 known-bad; scoped checklist: 0 fires on keepers, 16 fires
across 7/7 bad).

**Transferable rule:** every defect check carries its scope
condition in the same line as the check; an unscoped check is
a prune-candidate by default, and the pruning is recorded at
the gate run that finds it.
