## 1. Provenance ruling (read first)

The plan's distillation target was "the full defect list,
organised" **from the video**. Pass 1 refuted the premise: the
video names no defects, states no causes, and presents no defect
examples (OBSERVATION.md §1, §4, §6 claim C-35-1 REFUTED). A
taxonomy written as if extracted from this video would be
fabricated provenance — the exact failure this programme's
gates exist to catch.

What survives honestly:

- **The plan's own pre-viewing categories** — lighting /
  anatomy-pose / material / composition "sins", written in the
  plan's SHOULD-BE-SEEN on 2026-11-05, before any viewing.
  These are the estate's questions, not the creator's answers.
- **The estate's own defect record** — the TG-round censuses,
  the face-gate failure catalogues, and the character-art
  failure taxonomy already carry named, evidenced defect
  classes. Pass 3's candidate checks are derived from the
  intersection: plan categories × estate-evidenced defect
  classes, each check marked with its true source.

Per the protocol's three-way split, applied to the plan itself:

- **Adopt:** the plan's gate direction — a failure catalogue is
  worth more than a success reel; candidate checks pruned
  against known-good keepers.
- **Adapt:** the taxonomy's source — from "this video's named
  defects" (none exist) to the plan's categories instantiated
  by the estate's own evidenced defects.
- **Reject:** any attribution of the §3 classes to
  shadowyartsdirty or to video 3352570. Rejected with evidence:
  OBSERVATION.md §1–§4.

## 3. Estate-side taxonomy under the plan's categories

The classes below are the defect classes the estate's own gate
record already evidences (TG2/TG3/TG4 censuses in
`~/workspace/full-rigs-20261103/keeper-art-reanchor/`, the
face-plausibility failure catalogue, the character-art failure
taxonomy). They are organised under the plan's four categories
so Pass 3 can derive checks and Pass 4 can map coverage. Each
entry's evidence is an estate artifact, cited by path in
`PASS3-CANDIDATE-CHECKS.md`'s exercise record.

### Lighting
- **L-1 Skin-block wash** — unshaded salmon/tan blocks or
  gradient washes on limbs where the cast register shades skin
  (TG2-P1's tan leg wash; the TG rounds' recurring knee-patch
  class). Detection: visual at viewing size; eye-only in
  practice.
- **L-2 Flat/unlit read** — no directional shading read on the
  figure. *No instance in the exercised pools* (the estate's
  generators shade by default); carried as a class because
  3D-render lanes (the video's own medium) produce it
  routinely. Detection: visual.

### Anatomy / pose
- **A-1 Hand defect** — hands merged, hidden, claw-like, or not
  five-fingered (TG2-P2's splayed claw hands; TG2-A2's hands
  hidden in the hair mass). Detection: visual + native crop.
- **A-2 Non-neutral stance** — crossed/wide/dynamic stance
  where the benchmark specifies neutral standing (TG3/TG4 P3,
  P4, A1 splayed arms). Detection: visual against the
  benchmark's stance line.
- **A-3 Proportion / register break** — proportions or register
  contradicting the cast spec (TG2-A2's chibi register against
  the cel cast; TG2-P2's doll proportions). Detection: visual;
  proportion ratios partially measurable.

### Material (appearance attributes)
- **M-1 Garment spec violation** — a specified garment's
  colour/construction wrong (the Yui white/beige shirt fails
  across TG2-Y2, TG3-Y1, TG4-Y1; TG2-A3's bandeau construction
  for a specified dress). Detection: visual against spec;
  colour partially measurable.
- **M-2 Print errors** — print present where spec says none
  (TG4-Y2's alien-head chest print), glyph/text print
  (TG3-Y1), or specified print migrated off its garment
  (TG2-A4's cow-print on stockings instead of the dress).
  Detection: visual. **Must be spec-relative:** specified
  body text/tattoos exist in the keeper pool (Katya's "FREE
  USE", Cordelia's womb tattoo, D-799) and are not defects.
- **M-3 Invented motif/accessory** — floating hearts (TG2-A1,
  A2, A4; TG3/TG4 A3, A4), invented crown/hairpiece (TG3-Y3).
  Detection: visual census of the frame.

### Composition
- **C-1 Background leak** — anchor/reference elements in the
  background: tiled or giant faces (TG2-Y1's face-pattern
  ground), floating heads, hair-mass blobs. Detection: visual;
  the TG benchmark checks it FIRST.
- **C-2 Framing crop** — head/feet cropped or figure
  incomplete where the benchmark specifies full-body in frame
  (round-TG originals: head-cropped P3, waist-cropped A2).
  Detection: visual/measurable. **Must be benchmark-scoped:**
  deliberate partial compositions are keeper-legitimate in
  other artifact classes (Pass 3 exercise, §prune evidence).

### Face / identity (the plan's categories predate this class;
### the estate's record requires it)
- **F-1 Identity-feature defect** — void/black eyes with no
  iris/pupil (TG2-A2, TG2-A3), wrong eye colour, hair-colour
  drift (TG2-A4's brown for honey). Detection: visual + the
  face gates' measurements.
